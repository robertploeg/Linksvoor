# Festivalplanner export

Steps to publish on GitHub Pages:
1. Create a new GitHub repository (public).
2. Upload this file and rename it to `index.html` (must be exactly that name at the repo root).
3. In the repo: Settings -> Pages -> Source: Deploy from a branch -> Branch: main, folder: / (root) -> Save.
4. GitHub gives you a URL like https://<username>.github.io/<repo>/ after a minute.
5. Share that URL with friends - it works on any device with internet, no Claude account needed.

Note: this app syncs live via Firebase, so it needs normal internet access (which GitHub Pages provides) - it will NOT work if opened locally as a file:// URL without internet.
